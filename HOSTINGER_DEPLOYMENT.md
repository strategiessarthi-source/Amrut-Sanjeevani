# Deploying Amrut Sanjeevani to Hostinger

This guide provides step-by-step instructions to deploy this Vite + React application to Hostinger using standard **npm** and **Node.js** (without Bun or `bun.lockb`).

---

## 1. Quick Terminal Commands

Run these commands in your project root terminal before deploying:

```bash
# 1. Remove Bun lockfiles (safe to run even if already deleted)
rm -f bun.lock bun.lockb

# 2. Clean install dependencies using standard npm
npm install

# 3. Type check & build production assets with Vite
npm run lint
npm run build
```

After running `npm run build`, your production-ready static website will be created in the `dist/` directory.

---

## 2. Deploying to Hostinger (Standard Web Hosting / hPanel)

Hostinger Web Hosting serves static web applications lightning-fast using LiteSpeed / Apache.

### Step-by-Step Upload via Hostinger File Manager:

1. **Log into your Hostinger Account** and go to **hPanel**.
2. Select your domain or hosting plan and open **File Manager** (Files -> File Manager).
3. Navigate into the **`public_html`** folder.
4. **Delete or archive** any default placeholder files (e.g., `default.php`).
5. Open your local project folder and locate the **`dist`** folder generated by `npm run build`.
   > **Important:** Upload the **contents** inside `dist/` (such as `index.html`, `assets/`, `.htaccess`, images), **not** the `dist` folder itself.
   >
   > *Tip:* You can compress the contents of `dist` into a `.zip` file on your computer, upload `dist.zip` to `public_html` in File Manager, and click **Extract**.
6. Verify that `.htaccess` is present in `public_html`. A pre-configured `.htaccess` is included in `public/` and copied automatically to `dist/` on build to handle SPA routing and caching.

## 3. Alternative: Deploying via Hostinger Git / Deployment Webhook

If you have connected your GitHub/GitLab repository to Hostinger Git Deployment:

1. In Hostinger hPanel, go to **Advanced** -> **Git**.
2. Set the repository URL and branch (`main`).
3. Set the deployment build script or run via SSH:
   ```bash
   npm install
   npm run build
   cp -r dist/* public_html/
   ```

---

## 4. Alternative: Deploying on Hostinger VPS (Node.js)

If you are using Hostinger VPS running Ubuntu/Debian:

```bash
# Ensure Node.js 18+ or 20+ is installed
node -v
npm -v

# Clone and navigate to project
git clone <your-repo-url>
cd <repo-folder>

# Remove any bun lockfiles and install with npm
rm -f bun.lock bun.lockb
npm install

# Build static dist
npm run build

# If serving with Nginx, point root to /path/to/project/dist
# Or serve static files with pm2 / serve:
npx serve -s dist -l 3000
```
